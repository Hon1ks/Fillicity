# Fillicity

Portable Windows-приложение для автозаполнения любых форм и документов на экране
с помощью AI: показываешь область экрана, добавляешь данные (файл или картинку),
AI находит пустые поля и показывает поверх экрана, чем их заполнит (как overlay
в Google Переводчике) — по кнопке «Заполнить» реально вписывает значения в форму.

AI-модель подключается через **OpenRouter** (openrouter.ai) — один ключ даёт
доступ к моделям Anthropic, OpenAI, Google и др. с поддержкой изображений.

## Быстрый запуск (Windows)

1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/)
   (при установке отметьте галочку **Add python.exe to PATH**), либо используйте
   готовый дистрибутив вроде WinPython.
2. Распакуйте архив Fillicity, откройте в этой папке `cmd` или PowerShell.
3. Выполните:
   ```bat
   python -m pip install -r requirements.txt
   python fillicity.py
   ```
   (venv создавать не обязательно — можно ставить пакеты прямо в системный/
   портативный Python. Если всё же нужен venv и `python -m venv .venv`
   зависает на установке pip — это известная проблема WinPython/ensurepip,
   не связанная с Fillicity: используйте `python -m venv .venv --without-pip`,
   затем `.venv\Scripts\python -m pip install -r requirements.txt`.)
4. В открывшемся окне нажмите **⚙ Настройки**, вставьте OpenRouter API ключ
   (получить на [openrouter.ai/keys](https://openrouter.ai/keys), формат
   `sk-or-v1-...`) и при желании укажите модель (по умолчанию
   `anthropic/claude-sonnet-4.5` — любая vision-модель с openrouter.ai/models).

После первого запуска достаточно заново выполнять `python fillicity.py` из
этой же папки.

## Быстрый запуск (Linux/macOS, для разработки)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python fillicity.py
```

Ключ можно также задать через переменные окружения `OPENROUTER_API_KEY` и
`OPENROUTER_MODEL` вместо диалога Настроек.

## Как пользоваться

1. **Показать экран** — «Весь экран» или «Выбрать область» (перетаскиванием
   выделите нужный фрагмент — саму форму).
2. **Добавить файл или изображение** — данные, из которых нужно брать значения:
   md, txt, csv, xlsx, docx, pdf, png/jpg. Можно добавить несколько.
3. **Распознать и показать** — AI анализирует снимок экрана и присланные
   данные, поверх формы появляются полупрозрачные подсказки с предложенными
   значениями и плавающая панель с кнопкой «Заполнить».
4. **Заполнить** (в панели над формой или в главном окне) — приложение кликает
   по каждому найденному полю и реально вписывает значение.

## Сборка portable .exe для Windows

Собирать нужно **на Windows** (PyInstaller собирает под ту ОС, на которой
запущен):

```bat
build_windows.bat
```

Готовое приложение окажется в `dist\Fillicity\Fillicity.exe` — папку можно
копировать и запускать на любом Windows ПК без установки Python.

## Статус первой версии

Готово:
- окно с интерфейсом (выбор области экрана, загрузка данных, распознавание, заполнение);
- выбор области экрана / всего экрана;
- загрузка данных из md/txt/csv/xlsx/docx/pdf/изображений;
- AI-движок на OpenRouter (модель настраивается);
- overlay поверх формы с предложенными значениями;
- реальное заполнение формы кликами и вводом текста.

Известные ограничения v1 (что стоит улучшать дальше):
- точность координат полей зависит от качества распознавания моделью — на
  сложных/нестандартных формах возможны промахи, стоит проверять overlay перед
  нажатием «Заполнить»;
- работает с одним снимком области за раз (не «живое» непрерывное распознавание);
- pyautogui кликает по абсолютным координатам экрана — окно с формой должно
  оставаться на месте между распознаванием и заполнением.
